Always-on · online brain + thin client

An assistant with a characterful dot.

Doty keeps working between conversations. The brains live online — an agent loop, scheduler, memory and integrations — while a tiny floating dot on your desktop shows what it is doing, and a Discord bot answers you from anywhere.

View the source ↗ Read the plan

What it does

Not a chatbot in a browser tab — an agent that runs without you watching, fronted by a dot that communicates state.

◎

Always-on brain

A Fastify API and worker own the agent loop, scheduler and integrations. Close the laptop; work still finishes and notifies you.

✦

Presence, not a window

A transparent, always-on-top Tauri dot with a tray anchor, native notifications and a chat panel that stays out of the way.

⌘

Discord, natively

DMs, mentions and replies; scheduled reminders; and it can join a voice channel for music and speech.

🧠

Long-term memory

Optional, pgvector-backed retrieval that carries preferences and context across conversations and clients.

🛰

Harness awareness

Codex, OpenCode and T3 sessions appear as orbiting satellite dots with live status, and as messages in the chat.

⇄

Shared sessions

The desktop client and your Discord DMs can share one conversation, so memory and context follow you between devices.

How it works

Two halves joined by three frozen contracts, plus a Postgres core.

Desktop client

Tauri v2 · thin presence layer

  • Floating dot, tray, autostart, hotkey
  • Chat over REST + SSE, with offline queueing
  • Rust harness watcher (Codex · OpenCode · T3)
  • Native notifications and local tool bridge

Online service

Node · Fastify API + worker

  • Agent loop, scheduler and policy
  • Memory (Postgres + pgvector)
  • Discord · voice · tools · MCP
  • Replayable event log over SSE

desktop ◀── REST / SSE ──▶ service ◀── metadata ──▶ watchers
